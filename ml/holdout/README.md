# Human-labeled holdout

This folder is reserved for data **you** label by hand. Nothing here is used to
train, tune or select anything: `ml/train.py` reads it only to report, and it is
never split.

Do not put the following in this folder:

- `dataset/curated_space_dataset.csv` or any copy of it. Those rows are
  templated and a cue phrase decides the label, so evaluating on them produces a
  number that means nothing.
- `dataset/realistic_eval.csv`. Its labels (`Career`, `Other`, `Personal`,
  `Programming`, `Study`) are not in the `legacy-8` taxonomy and are not
  compatible with the current artifact.
- Anything generated by Gemini, or derived from an LLM. Self-evaluation is not a
  holdout.

## Expected format

A CSV with the columns `text` and `category`, matching
`ml/taxonomy/legacy-8.json` (or whichever taxonomy file the card names):

```csv
text,category
"React JWT authentication guide, step by step with screenshots",Tutorials
"Photo of a colour palette swatch board",Design
```

Build `text` the same way serving does, with
`curated_ml.build_text(title, description, tags)`. Labeling the raw screenshot
metadata keeps the holdout honest about the serving path.

## Size

The v1 guide will define 7 Intent x 7 Domain values. For the current
`legacy-8` placeholder, aim for at least 40 rows with every label represented,
preferably 100+. Small per-class counts make macro-F1 too noisy to tune against.

## What becomes possible once this exists

- An honest abstention threshold. Until then the card records
  `threshold_source: "default-unvalidated"` and the backend uses a fixed
  conservative default, because a threshold tuned on the synthetic split would
  be meaningless.
- A real accuracy claim in `readme.md`.
